# 11 — Release

**What to build:** **What to build:** Something a person outside this project can use — weights and code public,
with a model card saying what it is, what it was trained on, how it performs, and under what
licence.

**Blocked by:** 07, 09, 10

**Status:** ready-for-agent

- [ ] The checkpoint, the configuration and the model card are published, with the licence stated.
- [ ] The model card records the training corpus, the FLOPs budget, the measured bpb and the evaluation results.
- [ ] A third party can follow the model card's instructions to load the checkpoint and generate from it.
- [ ] The repository carries reproduction instructions for the training run.
- [ ] The write-up links to the artifact, and the artifact links back to the write-up.
