# 08 — Sampling and prompt continuation

**What to build:** **What to build:** The model can generate text — given a byte prompt, it continues it, with
temperature and top-k under the user's control.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] A sampling loop produces continuations from a byte prompt, with temperature and top-k applied.
- [ ] Generation is deterministic under a fixed seed.
- [ ] Generated bytes that are not valid UTF-8 are reported rather than silently replaced.
- [ ] Sampling runs from a checkpoint loaded from disk, not from a model in memory.
- [ ] A byte-level prompt round-trips: the prompt the user supplies is the prefix of what comes back.
